# 抖音在线人数与贡献榜

录制抖音直播时，**在线人数**与**贡献榜**的变化快照会随弹幕 XML 一并保存，并可在浏览器预览里按时间查看。

::: tip 适用范围
仅抖音支持。其它平台不采集这两类数据，XML 里不会出现 `<room>` / `<rank>`，预览也不显示对应区块。
:::

## 开关

| 层级       | 位置                                                            |
| ---------- | --------------------------------------------------------------- |
| 全局配置   | 设置 → 录制 → 抖音 → **在线人数** / **贡献榜**                  |
| 单房间配置 | 录制工具 → 添加/编辑直播间 → 同名两项（右侧可勾选「全局」跟随） |

- **默认开启**。
- 两项只在「弹幕录制」开启时可用 —— 关闭「弹幕录制」后 XML 本身就不会生成，这两项会置灰。
- 关闭后的效果：
  - 在线人数：不写 `<room>`；
  - 贡献榜：不写 `<rank>` 与 `<rank_users>`；
  - 两者都会让预览里对应的导航项与表格**整体消失**（不是留一张空表）。

## 在线人数

### 数据写在哪儿

```xml
<room ts="123.456" online="1234" />
```

- `ts`：**相对录制开始**的秒数，预览会格式化成 `HH:MM:SS.mmm`；
- `online`：在线人数，按字符串存储。
- **只记变化**：与上一条数值相同就跳过，因此稳定的直播间节点很少，人数频繁波动的直播间节点会多。

### 取值口径

只认 `RoomStatsMessage` 的 `displayValue`，原因是有实测依据的：

- `RoomUserSeqMessage.total` 是**滞后快照** —— 同一时刻与 `displayValue` 相差 +219 ~ -488，且人数越高偏差越负，不能当实时人数；
- `onlineUserForAnchor` 是主播端口径的**格式化文本**（如「1.3万」），无法落到数值字段。

## 贡献榜

### 数据写在哪儿

```xml
<rank ts="123.456">
  <u uid="97814778350" nick="米大王" />
  <u uid="7630365130980066353" nick="神秘人•S" />
  <u uid="432566925526460" nick="黎嗲域" />
</rank>
<rank_users>
  <user uid="97814778350" nick="米大王" a="100x100/aweme-avatar/tos-cn-avt-0015_xxxx" />
</rank_users>
```

- 一条 `<rank>` 是**一次快照**，`<u>` 的**顺序即名次**（第一个就是第 1 名）；
- `nick` 取不到时不写该属性，预览按 uid 显示；
- `<rank_users>` 是**声明区**：每个 `(uid, 昵称)` 首次出现时登记一次，**头像只在这里写**（`a`），`<u>` 里不重复 —— 与礼物图标表的做法一致；
- **只记变化**：判定是**整条保序 `(uid, 昵称)` 序列**，所以换人、名次变动、同一 uid 改名都算变化；服务端按固定节拍重推的相同内容会被吃掉。

### 已知限制

- **没有贡献值**：服务端下发的榜单条目里只有用户，`score_str` / `profile_hidden` 一个字节都没出现过（实测 204/204 条目均未下发）。
  因此预览只显示名次、昵称与头像，**不显示分数**，也无法按贡献值排序。
- 快照通常只含前 3 名；若某条快照内有成员缺 `uid`，该条会被丢弃（`uid` 是唯一标识），此时该行可能不足 3 列。
- 头像只有在该用户**首次登记**时随消息带上了 `AvatarThumb.uri` 才会写进 `<rank_users>`；没带时预览只显示昵称。

## 预览里长什么样

两个独立区块，各自是一个可折叠的「变化明细」：

| 区块     | 表头                                   | 说明                     |
| -------- | -------------------------------------- | ------------------------ |
| 在线人数 | 变化时间 / 在线人数                    | 只记人数变化             |
| 贡献榜   | 变化时间 / 第 1 名 / 第 2 名 / 第 3 名 | 末行即当前榜（高亮显示） |

节点数不超过展开阈值时区块默认展开，超过则折叠，点开可看全部变化。

## 想抓原始报文

想看平台下发的原始消息时，开启对应转储开关：设置 → 录制 → 抖音 → **调试** →
「在线人数原始报文」/「贡献榜原始报文」，产物为视频同目录下的 `_room_raw.jsonl` / `_rank_raw.jsonl`。
开关位置、体量与清理方式见[排障与调试](/features/debug)。
